# Phase 14.6F Google Workspace Implementation Plan

> Execute with test-driven development, small local commits, and fresh
> verification before any completion claim.

**Goal:** Deliver one secure Google Workspace OAuth bundle for Calendar and
Gmail with coordinated token lifecycle, safe Test/Disconnect, and bounded
server-only appointment and email operations.

**Architecture:** Pure contracts validate all untrusted provider/input data.
A fixed-origin server adapter owns OAuth, refresh, UserInfo, Calendar, Gmail,
and revocation calls. Existing organization-scoped integration rows are updated
atomically as a two-provider bundle with identical encrypted credentials and
identity metadata. Settings actions re-authorize every lifecycle operation.

**Design:**
`docs/superpowers/specs/2026-08-21-phase-14.6f-google-workspace-design.md`
