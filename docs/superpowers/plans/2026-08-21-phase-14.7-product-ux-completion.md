# Phase 14.7 Product UX Completion Implementation Plan

> Execute with test-driven development, small local commits, visual browser
> verification, and fresh evidence before any completion claim.

**Goal:** Finish Revora's protected product UX with truthful navigation,
provider branding, real organization-scoped Search/Activity/Calendar/AI
surfaces, validated workspace preferences, and a consistent accessible
responsive pass.

**Architecture:** Pure product contracts normalize preferences, search input,
provider responses, activity rows, and qualification metadata. Server actions
re-authorize the active organization and return narrow safe DTOs. New routes
remain Server Components with small Client Components only for interactive
dialogs and forms. Existing tables and provider adapters are reused without a
schema change.

**Design:**
`docs/superpowers/specs/2026-08-21-phase-14.7-product-ux-completion-design.md`
