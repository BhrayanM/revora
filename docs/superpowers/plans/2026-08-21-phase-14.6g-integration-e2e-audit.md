# Phase 14.6G Complete Integration E2E Audit Plan

> Execute as a deterministic audit: evidence first, minimal remediations only,
> and fresh verification before closure.

**Goal:** Establish one repeatable local integration gate across all ten
provider catalog entries, remediate validated cross-cutting findings, and
document live blockers without performing unauthorized external mutations.

**Design:**
`docs/superpowers/specs/2026-08-21-phase-14.6g-integration-e2e-audit-design.md`

---

## Task 1: Create the cross-provider audit harness

**Files:**

- Create: `scripts/verify-integration-e2e-audit.mjs`
- Modify: `package.json`

### Steps

1. Add source/migration assertions for the exact provider catalog, database
   allowlist, tenant predicates, safe DTOs, specialized action guards,
   encryption, OAuth-state/PKCE lifecycle, webhook boundaries, retry/
   idempotency, Google one-attempt mutations, and client import boundaries.
2. Compare committed migrations `00001`-`00035` to the 14.6F checkpoint and
   compare normalized working content to current Git blobs.
3. Add `test:integration-e2e` that runs automation, communication, Tally,
   Google Workspace, and cross-provider audit suites in order.
4. Run the new audit and preserve its expected PKCE-at-rest failure.
5. Commit only after Task 2 makes the gate pass.

## Task 2: Remediate the confirmed PKCE finding

**Files:**

- Modify: `src/lib/integrations/oauth.ts`
- Modify: `scripts/verify-integration-e2e-audit.mjs`

### Steps

1. Assert that the stored verifier passes through `encryptCredential` and the
   validated verifier through `decryptCredential` only after all state checks.
2. Confirm the assertion fails against the checkpoint code.
3. Encrypt before update; decrypt after state validation and consumption.
4. Fail closed on malformed/decryption failures without returning details.
5. Run aggregate audit, lint, and typecheck.
6. Commit: `fix(integrations): encrypt oauth pkce verifiers`.

## Task 3: Complete source-to-sink audit and remediate validated findings

**Files:**

- Modify only files directly implicated by a reproducible finding.
- Modify: `scripts/verify-integration-e2e-audit.mjs`

### Steps

1. Trace credential inputs through persistence, provider requests, safe DTOs,
   logs/audits, disconnect, and refresh for every provider.
2. Trace organization IDs through settings actions, OAuth callbacks, public
   webhooks, provider mappings, executions, and connection repositories.
3. Trace retry/idempotency behavior for automation, Slack, Tally, Google, and
   read-only Twilio.
4. Add one failing regression assertion per validated finding before the fix.
5. Make the smallest behavior-preserving remediation and rerun all affected
   phase suites.
6. Do not alter migrations `00001`-`00035`.
